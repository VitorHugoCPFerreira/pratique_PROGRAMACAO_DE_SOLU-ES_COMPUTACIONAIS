# Sistema de Eventos - Pratique

## Descrição
Sistema em Java para cadastro de usuários e eventos, consulta e gerenciamento de participação.

## Arquivos principais
- `Main.java`: contém o menu e lógica do sistema
- `Usuario.java`: classe de cadastro de usuários
- `Evento.java`: classe de cadastro de eventos
- `Categoria.java`: enumeração de categorias de eventos

## Como rodar
1. Abrir o projeto em Eclipse
2. Executar `Main.java`
3. Seguir instruções no console
